# HIGHER OR LOWER: THE QUESTIONS
#
# This file is every card in the Higher or Lower game on jurtu.com.
# Change it as often as you like (every week is great). When the change is on GitHub (main), the game uses it.
#
# How it works:
#   TITLE: is shown at the top of the game, for example the name of this week's quiz. You can leave it out.
#   TOPIC: starts a new group of cards. Both cards in a guess always come from the same TOPIC.
#          Put one emoji first (it is the picture on the cards), then the topic name.
#   UNIT:  the word shown after every number in that topic, like "people" or "km/h". You can leave it out.
#   Name = number   is one card. Write the number with digits only. Spaces are fine: 390 000.
#                   For a half number use a dot: 4.5
#                   A card can start with its own emoji (🐆 Cheetah = 110). If it has none, it gets the topic's emoji.
#   Lines that start with # are notes for you. The game skips them. Empty lines are skipped too.
#
# Every topic needs at least 2 cards. 10 or more cards in a topic is best.
# If a line is written wrong, the game just skips that line.
# To check your changes before they go live, run  python3 serve.py  and open the game:
# on your own computer the game lists any line it had to skip, under the game.
